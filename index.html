Frequently Asked Questions

Everything you need to know about OUSO platform.

Are my files safe and private?

Yes! All image, PDF, and text tools run entirely inside your browser using client-side code. Your files never leave your device.

Do I need to install anything?

No installation is required. However, you can save and install OUSO as a PWA app on your desktop or phone home screen for quick offline access.

Are all tools free to use?

Yes, all core utilities and working tools are completely free to use without registration.
